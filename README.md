# Step_semester_3

Semester 3 coursework repository — Version Control & Daily Workflow Standard.

Branch layout:
- `main` — this README only, updated with a dated log entry after every session
- `develop` — empty base Java project skeleton (no code)
- `feature/session_n` — one branch per session, containing that session's solved problems under
  `class_problems` (live-coding) and `assigment_problems` (take-home) sub-packages
